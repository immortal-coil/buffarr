Configuration

Cleanup

The single size cutoff that decides what counts as a real game. Identified games smaller than this drop out of the Library, and it's the threshold the Unmanaged cache's "Clean up" button sweeps. Prefilled and monitored entries are always kept regardless of size. Use nginx-style sizes (k, m, g, t — e.g. 100m). Takes effect immediately, with no redeploy.

Current: {{.MinGameSizeHuman}}
Cache size limit

Cap the total cache size. When the cache exceeds it, Buffarr automatically deletes the least-recently-used unlocked games until back under the cap. Locked games are never deleted — so locking more than the cap lets the cache go over it (Lock wins). Leave blank for no Buffarr cap. Use nginx-style sizes (e.g. 450g).

Heads up: this cap is larger than the cache disk ({{.DiskTotalHuman}}), so it can never be reached and Buffarr won't auto-evict on its own. Set it at or below the disk size.

Cache eviction

Pause automatic eviction so nothing is deleted while the cache is in use — e.g. during a LAN event, when a game that's just over the cap might otherwise be evicted right before someone installs it. Pick a window and eviction resumes on its own when it elapses; Resume now ends it early. The cap above is still tracked throughout. (Locked games are never evicted regardless.)

Cache performance

The Dashboard shows total bytes served from cache and the cache hit-rate. Reset the counter to start a fresh measurement (e.g. before an event). This only clears the stats; cached games are untouched.

Background artwork

Show a random cached game's artwork as a faded background behind the Dashboard, Library, and Preload pages.
