How to set your DNS
Windows 11 / 10
Settings → Network & Internet → your Wi-Fi or Ethernet → Edit next to "DNS server assignment" → Manual → turn on IPv4 → set Preferred DNS to {{$ip}} → Save.
macOS
System Settings → Network → your connection → Details… → DNS → click + and add {{$ip}} at the top of the list → OK → Apply.
Steam Deck
Switch to Desktop Mode → network icon → your connection → Settings → IPv4 → Method "Automatic (Addresses only)" → DNS Servers {{$ip}} → Apply.
PlayStation / Xbox / Switch
In the console's network settings, set up the connection manually and set DNS to Manual: Primary DNS {{$ip}}, leave Secondary blank (or your router). IP and gateway can stay automatic.
